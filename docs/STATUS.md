## Cara tes cepat (tanpa native)
1. Run app. Buka Explorer > engine/api.json.
2. Isi baseUrl + apiKey + model. Contoh Ollama di laptop: baseUrl "http://192.168.x.x:11434", model "llama3.2", apiKey "".
3. Simpan, lalu chat di panel bawah. Ubah chat/params.json (temperature dll), Simpan, chat lagi.
